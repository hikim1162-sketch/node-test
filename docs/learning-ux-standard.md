# ValueTime 학습 페이지 기본 규칙

이 문서는 단어장, 매일 1문장, 유의어, 표현, 테스트 등 모든 학습 페이지에 공통 적용한다.

## 1. 화면 구조

- 학습과 직접 관계없는 대형 히어로 영역을 만들지 않는다.
- 해당 페이지의 기능을 다시 설명하는 장황한 소개 문구를 넣지 않는다.
- 페이지에 들어오면 오늘 학습할 콘텐츠와 현재 상태가 먼저 보여야 한다.
- 메인 콘텐츠의 최대 너비, 좌우 여백, 시작 위치는 다른 메인 학습 페이지와 동일하게 맞춘다.
- 새로운 화면을 만들기 전에 단어장과 매일 1문장의 기존 구조를 기준으로 비교한다.

## 2. 공통 학습 상태

모든 학습 기능은 아래 다섯 요소를 기본으로 제공한다.

1. 완료: 동일한 Clear 명칭, 위치, 색상과 상태 전환 규칙을 사용한다.
2. 오답: 틀린 항목을 자동 저장하고 오답 복습에서 다시 학습할 수 있어야 한다.
3. 테스트: 학습한 범위에서 문제를 출제하고 결과를 즉시 반영한다.
4. 저장: 다시 볼 항목을 나만의 학습장과 복습 시스템에 연결한다.
5. 진도율: 현재 분량, 완료 수, 전체 수와 진행 상태를 일관된 방식으로 표시한다.

## 3. 표준화 원칙

- 같은 행동에는 같은 용어를 사용한다.
- 같은 행동 버튼은 같은 위치와 시각적 상태를 사용한다.
- 완료 상태는 카드, 진도율, 테스트와 저장 데이터에 함께 반영한다.
- 별도 구현보다 기존 공통 컴포넌트와 패턴 재사용을 우선한다.
- 기능 추가 후 데스크톱과 모바일 실제 화면을 확인한다.
- 빌드 성공만으로 화면 검증을 대신하지 않는다.

## 4. 완료 전 점검

- 불필요한 히어로나 중복 설명이 없는가
- 다른 메인 페이지와 콘텐츠 폭이 같은가
- Clear 버튼의 명칭과 위치가 표준과 같은가
- 오답, 테스트, 저장, 진도율이 연결되어 있는가
- 고정 버튼이나 알림이 학습 조작을 가리지 않는가
- 실제 브라우저에서 주요 상태를 직접 확인했는가
