# ValueTime 제품 표준 요구사항

> 상태: 적용 기준 문서  
> 최종 갱신일: 2026-07-31  
> 적용 범위: ValueTime 전체 모드와 학습 기능  
> 원칙: 사용자가 새 요구사항을 전달하면 구현과 함께 이 문서를 갱신한다.

## 1. 공통 제품 원칙

- 사용자가 환경설정에서 `안 보임`으로 지정한 메뉴와 기능은 사이드바뿐 아니라 오늘의 학습, 진행 현황, 추천 영역 등 모든 진입점에서 숨긴다.
- 숨겨진 항목을 제외한 화면 번호는 항상 `1, 2, 3…` 순서로 다시 매긴다. 번호가 건너뛰면 안 된다.
- 같은 기능은 모든 모드에서 위치, 너비, 버튼 형태와 동작을 가능한 한 동일하게 유지한다.
- 화면의 불필요한 빈 공간을 만들지 않고, 주요 콘텐츠는 지정된 공통 폭과 정렬선을 따른다.
- 사용자가 완료한 상태, 오답, 저장 항목과 진도는 서로 연결되어야 한다.
- 기능을 변경하면 관련 자동 테스트를 추가하거나 갱신하고 빌드 및 테스트를 통과시킨다.
- 완료된 변경은 커밋하고 원격 저장소에 푸시한다. 실제 운영 배포 여부는 원격 푸시와 구분하여 확인한다.

## 2. 상단 헤더

- 학습 모드 선택은 `일반 / 수능`으로 구분한다.
- 학령 선택은 `초등 / 중등`으로 구분한다.
- `연속 학습` 표시는 사용하지 않는다.
- 사용자 정보와 모드 선택 영역은 메인 콘텐츠의 왼쪽 정렬선에 맞춘다.

## 3. 오늘의 학습

- 환경설정의 메뉴 표시 여부를 오늘의 학습 카드에도 그대로 적용한다.
- `표현 업그레이드`를 안 보이도록 설정하면 오늘의 학습에도 표시하지 않는다.
- 오늘의 학습 카드 번호는 현재 보이는 카드만 기준으로 연속 번호를 부여한다.
- `유의어 공부`는 다른 항목을 숨겨도 실제 보이는 순서에 맞는 번호를 표시한다.
- 오늘의 단어와 단어장 테스트는 서로 중복 배치하지 않는다. 단어장 테스트는 오늘의 단어 학습 흐름 안에서 제공한다.

## 4. 유의어 학습

### 4.1 학습 흐름

- 수능 모드의 유의어 학습이 끝나면 테스트를 바로 표시한다.
- 테스트 자동 전환 기준은 모든 메인 단어의 `Meaning Clear`와 모든 관련 표현 학습 완료다.
- `Meaning Clear`만 완료했다고 테스트로 넘어가면 안 된다.
- 유의어 학습 팝업의 사용자 노출 문구는 영어로 표시한다.
- 다음 홍보 문구는 표시하지 않는다.
  - `30-DAY SYNONYM COURSE`
  - `하루 3~4개씩 정확하게`
  - `100개를 한꺼번에 외우지 않고 30일 동안 뜻·예문·뉘앙스를 나눠 학습합니다.`
- 해당 상단 영역의 세로 높이는 기존보다 약 30% 줄인다.

### 4.2 단어 표시

- 메인 단어와 관련 단어 옆에는 항상 발음기호를 표시한다.
- 발음기호는 수능 단어장에서 사용하는 IPA 표기 형식과 동일하게 사용한다.
- 발음기호가 없거나 `/null/`로 표시되면 안 된다.

### 4.3 테스트

- 객관식 문제는 `유의어를 모두 고르시오` 형식으로 출제한다.
- 선택지는 매번 무작위 순서로 배치한다.
- 그날 학습한 네 단어 모두에 대해 유의어 하나를 직접 입력하는 문제 유형을 포함한다.
- 정답을 맞히면 단어 옆에 한국어 뜻을 표시한다.
- 오답인 경우 `다시 풀기` 기능을 제공한다.
- 완료 문구와 버튼 등 사용자 노출 문구는 현재 화면 언어와 일치시킨다.

## 5. 수능 단어장

- 저장 단어 영역의 글자 크기는 본문과 비교해 지나치게 작지 않게 유지한다.
- 저장 단어도 메인 단어와 동일한 가독성 기준을 적용한다.
- 발음기호는 유의어 학습에서도 재사용하는 표준 IPA 데이터로 취급한다.
- 수능 모드의 상단 콘텐츠와 학습 탭 영역 폭은 기존 전체 폭 대비 약 20% 줄이고 가운데 정렬한다.

## 6. Daily Test

- Daily Test는 독립적으로 매일 학습할 수 있어야 한다.
- 날짜별로 새로운 문제를 제공한다. 매일 같은 고정 문제를 반복하면 안 된다.
- 날짜를 기준으로 문제 세트와 선택지 순서를 안정적으로 변경한다.
- 단어, 문장 표현, 문법 등 문제 유형을 다양하게 구성한다.
- 이전 날짜와 다음 날짜의 테스트로 이동하는 버튼을 항상 명확하게 표시한다.
- 이동 버튼은 테스트 하단에서 찾기 어렵게 두지 말고 상단 또는 날짜 정보 주변의 고정 위치에 둔다.
- TOEIC RC 문제는 Daily Test에서 제외한다.
- TOEIC RC 문제는 `매일 토익 풀기`에 포함한다.
- 문제 문구와 선택지의 언어가 일치해야 한다. `다음 영어 단어`라고 질문하면 실제 영어 단어를 제시해야 한다.

## 7. 수능 유의어 화면 레이아웃

- 유의어 학습 화면의 전체 콘텐츠 폭은 기존 대비 약 20% 줄이고 가운데 정렬한다.
- 탭, 진행 표시줄과 학습 카드가 동일한 좌우 정렬선을 사용한다.
- 넓은 화면에서도 콘텐츠가 한쪽으로 치우치거나 과도한 빈 공간이 생기지 않게 한다.

## 8. 추천 학습 링크

- 일반 모드와 수능 모드에 동일한 추천 학습 링크 영역을 제공한다.
- 추천 학습 링크는 헤더와 메인 콘텐츠 사이의 동일한 위치에 고정한다.
- 모드 전환으로 추천 링크가 사라지거나 위치가 바뀌면 안 된다.

## 9. 푸터

- 푸터는 일반 모드와 수능 모드를 포함한 모든 모드에 항상 표시한다.
- 푸터는 다음 항목을 링크 형태로 제공한다.
  - ValueTime 소개
  - 이용약관
  - 불편사항 신고
  - 개인정보처리방침
  - Copyright & Source Policy
  - 사이트맵
- 개인정보처리방침 링크에 노란색 강조를 사용하지 않는다.
- 대표이사는 `kai`로 표시한다.
- 회사 정보와 저작권 문구를 함께 표시한다.
- 서비스의 기존 시각 스타일과 어울리는 기업형 푸터 형태를 사용한다.

## 10. 변경 완료 기준

각 요구사항은 다음 조건을 모두 만족해야 완료로 본다.

1. 화면과 실제 동작이 요구사항에 맞게 구현됐다.
2. 설정값이 관련된 모든 화면에 동일하게 반영됐다.
3. 데스크톱과 주요 반응형 너비에서 레이아웃을 확인했다.
4. 관련 자동 테스트가 통과했다.
5. 프로덕션 빌드가 성공했다.
6. 변경사항을 커밋하고 원격 저장소에 푸시했다.
7. 운영 사이트 배포가 필요한 경우 배포 완료 여부를 별도로 확인했다.

## 11. 요구사항 기록 형식

새 요청은 구현 전에 아래 형식으로 해석하고, 구현과 함께 관련 절에 반영한다.

```text
요청:
적용 화면:
기대 동작:
표시 문구:
예외 조건:
완료 확인:
```

## 12. 사용자 요청 원문 기준 체크리스트

아래 목록은 대화에서 전달된 제품 요구사항을 빠짐없이 추적하기 위한 원장이다. 비슷한 요청도 임의로 합쳐서 삭제하지 않고 각각 남긴다.

### 12.1 작업·배포 운영

- 사이트를 실행해서 실제 화면을 확인한다.
- 변경 작업이 끝나면 로컬 변경사항만 남겨두지 않는다.
- 변경사항을 Git에 커밋하고 원격 저장소로 푸시한다.
- CI/CD가 연결된 경우 원격 푸시 이후 배포 결과까지 확인한다.
- 원격 저장소 푸시와 실제 사이트 배포를 같은 의미로 보고하지 않는다.
- GitHub Desktop의 Changes에 작업 파일이 남아 있으면 완료로 보고하지 않는다.
- 사용자가 별도로 푸시하지 않아도 요청받은 작업 범위의 커밋과 푸시를 처리한다.

### 12.2 대화 안정성

- 작업 중 사용자가 채팅창에 입력한 글이 사라지는 문제를 사이트의 채팅 버튼 문제로 오해하지 않는다.
- 사용자가 연속으로 보낸 짧은 문장은 하나의 요청으로 이어서 해석한다.
- 작업 도중 들어온 추가 설명과 이미지를 현재 작업 요구사항에 합친다.
- 입력창 유실 문제는 ValueTime 코드 변경과 Codex 대화창 자체 문제를 구분해서 설명한다.

### 12.3 수능 모드 유의어 학습

- 유의어 학습을 마치면 테스트가 바로 나타나게 한다.
- 테스트로 자동 전환하는 기준은 마지막 관련 표현까지 모두 완료한 시점이다.
- `Meaning Clear`만 완료한 상태에서는 테스트로 넘어가지 않는다.
- 객관식 문제는 하나만 고르는 방식이 아니라 `유의어를 모두 고르시오` 방식으로 출제한다.
- 유의어 학습 팝업 전체 사용자 문구를 영어로 번역한다.
- 객관식 보기는 정답이나 학습 순서 그대로 두지 않고 무작위로 배치한다.
- 그날 학습한 네 단어 모두에 대해 유의어 하나를 직접 입력하는 문제를 추가한다.
- 정답을 맞힌 뒤에는 해당 단어 옆에 한국어 뜻을 표시한다.
- 틀린 문제에는 다시 풀기 기능을 제공한다.
- `선택 Complete`처럼 한국어와 영어가 섞인 문구를 사용하지 않는다.
- 메인 단어 옆에 항상 발음기호를 표시한다.
- 관련 단어 옆에도 항상 발음기호를 표시한다.
- 발음기호는 네이버 사전 예시와 수능 단어장에서 사용 중인 정상적인 IPA 형태를 기준으로 한다.
- `/null/`이나 비정상적인 발음기호 모양을 노출하지 않는다.
- `30-DAY SYNONYM COURSE` 문구를 삭제한다.
- `하루 3~4개씩 정확하게` 문구를 삭제한다.
- `100개를 한꺼번에 외우지 않고 30일 동안 뜻·예문·뉘앙스를 나눠 학습합니다.` 문구를 삭제한다.
- 위 문구가 있던 유의어 학습 상단 영역의 세로 폭을 약 30% 줄인다.
- 유의어 학습의 탭과 콘텐츠 전체 폭을 약 20% 줄인다.
- 줄인 영역은 화면 가운데에 정렬하고 공통 콘텐츠 정렬선을 맞춘다.

### 12.4 수능 단어장

- 수능 단어장의 `② 저장 단어` 글자 크기를 가독성 있게 키운다.
- 수능 단어장에 이미 적용된 정상 발음기호 형식을 유의어 학습에도 동일하게 적용한다.
- 수능 모드 상단의 모드 선택, 학습 범위, 단계 탭 영역 폭을 약 20% 줄인다.
- 줄인 수능 모드 영역은 지정된 메인 콘텐츠 정렬선에 맞춘다.

### 12.5 추천 학습 링크

- 수능 모드에도 일반 모드와 동일한 추천 학습 링크를 표시한다.
- 추천 학습 링크는 모든 모드에서 헤더와 본문 사이의 동일한 위치에 고정한다.
- 수능 모드에서만 보이거나 일반 모드에서 사라지면 안 된다.

### 12.6 푸터·저작권·출처

- 출처 정책은 하단 푸터에 `Copyright & Source Policy` 링크로 제공한다.
- 푸터는 제공된 기업 사이트 예시와 비슷한 정보형 구조로 만든다.
- 대표이사는 `kai`로 표시한다.
- 개인정보처리방침 링크의 노란색 배경이나 강조색을 제거한다.
- 푸터에는 ValueTime 소개, 이용약관, 불편사항 신고, 개인정보처리방침, Copyright & Source Policy, 사이트맵을 표시한다.
- 푸터는 일반 모드와 수능 모드 사이에 관계없이 항상 표시한다.
- 회사 정보와 Copyright 문구를 함께 표시한다.

### 12.7 헤더·모드 선택

- 불꽃 아이콘 옆 `day streak`는 의미가 분명한 한국어로 변경한다.
- 연속 학습 표시는 왼쪽 정렬한다.
- 이후 요청에 따라 불꽃 아이콘과 `12일 연속 학습` 표시 자체를 제거한다.
- `일반 / 수능` 선택과 `초등 / 중등` 선택은 서로 다른 기준이므로 시각적으로 명확히 구분한다.
- `초등 / 중등` 구분을 없애거나 일반·수능과 같은 선택으로 취급하지 않는다.

### 12.8 Daily Test

- Daily Test 문제를 매일 똑같이 고정하지 않는다.
- Daily Test만 단독으로 학습하는 사용자도 매일 새로운 문제를 풀 수 있게 한다.
- 날짜별로 문제를 교체한다.
- 단어 뜻 하나, 문법 하나만 반복하는 단순한 구성에서 벗어난다.
- 문제 유형을 다양하게 구성한다.
- Daily Test 화면의 과도한 오른쪽 빈 공간을 없애고 콘텐츠 폭을 적절히 사용한다.
- Daily Test에 이전 날짜와 다음 날짜 이동 기능을 추가한다.
- 이전·다음 버튼을 사용자가 즉시 찾을 수 있는 위치에 항상 표시한다.
- 버튼이 화면 하단 밖이나 스크롤해야만 보이는 위치에 있으면 안 된다.
- TOEIC 문제는 Daily Test에서 제외한다.
- 제외한 TOEIC 문제는 `매일 토익 풀기`에 추가한다.
- `다음 영어 단어의 뜻으로 가장 적절한 것은?`이라는 문구를 쓸 때 실제 영어 단어가 문제에 보여야 한다.
- 단어장 테스트를 Daily Test의 독립 탭으로 중복 배치하지 않는다.
- 단어장 테스트는 오늘의 학습에 있는 `오늘의 단어` 흐름에서 제공한다.

### 12.9 오늘의 학습·환경설정

- 환경설정에서 `표현 업그레이드`를 `안 보임`으로 설정하면 오늘의 학습 카드에서도 숨긴다.
- 환경설정의 숨김 설정은 사이드바에만 적용하지 않고 관련 모든 화면에 적용한다.
- 숨김 항목 때문에 오늘의 학습 번호가 `1, 2, 3, 4, 5, 6, 8…`처럼 건너뛰면 안 된다.
- 현재 보이는 카드만 기준으로 `1, 2, 3…` 연속 번호를 다시 부여한다.
- 유의어 공부 카드도 실제 표시 순서에 맞는 번호를 사용한다.

### 12.11 단어 뜻 데이터 표시

- 품사별 뜻에는 실제 한국어 뜻을 먼저 표시한다.
- `(=perm)`처럼 다른 표제어만 가리키는 축약 참조를 단독 뜻으로 노출하지 않는다.
- 사전 원문이 축약 참조만 제공하면 해당 단어의 한국어 뜻을 보완하고 참조 표기는 뒤에 덧붙인다.
- `permanent`의 명사 뜻은 `파마, 파마한 머리 (=perm)`로 표시한다.

### 12.12 월간 단어 시험

- 오답을 선택한 직후 정답 선택지와 정답 뜻을 공개하지 않는다.
- 오답이면 `오답입니다`를 표시하고 현재 문제의 선택 가능한 화면으로 즉시 갱신한다.
- 사용자가 별도의 `다시 풀기` 버튼을 누르게 하지 않는다.
- 오답 직후 같은 문제에서 다른 보기를 바로 선택할 수 있게 한다.
- 불필요한 확인, 초기화 또는 재시도 버튼을 학습 흐름 중간에 추가하지 않는다.
- 정답을 맞힌 뒤에만 정답 뜻과 다음 문제 이동 버튼을 표시한다.
- 문제의 정답 뜻은 표제어의 품사와 반드시 일치해야 한다.
- 동사 `predict`의 정답은 명사형 `예언, 예측`이 아니라 `예측하다, 예언하다`로 표시한다.
- 월간 시험은 단어 원본의 단순 뜻보다 품사별 사전 뜻을 우선 사용한다.
- 시험 문제의 단어 영역에 `명사`, `동사`, `형용사`, `부사` 품사를 함께 표시한다.
- 형용사 `preceding`은 명사형처럼 보이는 `이전`이 아니라 `앞선, 이전의, 선행하는`으로 표시한다.

## 14. 즉시 피드백·재시도 표준

- 객관식 학습에서 오답을 고르면 `오답입니다`를 즉시 표시한다.
- 정답을 공개하지 않은 채 현재 문제를 곧바로 다시 선택 가능한 상태로 갱신한다.
- 재시도가 필수인 흐름에서는 `다시 풀기`, `확인`, `초기화` 같은 중간 버튼을 두지 않는다.
- 사용자의 다음 행동은 같은 화면에서 곧바로 다른 답을 선택하는 것이어야 한다.
- 정답을 맞혔을 때만 정답 정보와 다음 단계 이동 버튼을 제공한다.
- 이 원칙은 월간 단어 시험뿐 아니라 같은 방식의 단어·유의어 객관식 테스트에도 공통 적용한다.

### 12.10 레이아웃 공통

- 표시 폭을 줄이라는 요청은 콘텐츠를 왼쪽에 방치한다는 의미가 아니다.
- 폭을 줄인 영역은 가운데 정렬하거나 사용자가 표시한 공통 정렬선에 맞춘다.
- 큰 화면에서 콘텐츠가 절반에만 몰리고 나머지가 빈 공간으로 남지 않게 한다.
- 기능 버튼은 사용자가 찾는 문맥과 위치에 배치한다.

## 13. 상충 요청 처리

- 같은 요소에 대한 최신 요청이 이전 요청을 대체하면 이전 기록을 삭제하지 않고 `대체됨`으로 남긴다.
- 현재 적용 기준은 가장 최근의 구체적인 요청으로 한다.
- 예: 연속 학습 문구를 한국어로 바꾸라는 요청 뒤에 해당 표시를 없애라는 요청이 있었으므로 현재 기준은 `표시 제거`다.
- 요구사항을 구현할 때 원장과 현재 적용 기준이 다르면 현재 적용 기준을 우선하고, 원장에는 변경 이력을 보존한다.
